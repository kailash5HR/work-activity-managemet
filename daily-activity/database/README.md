# Daily Activity Database

This project includes a local SQLite database for user and activity data.

## Files

- `db.js` opens the SQLite database connection
- `init.js` creates the schema
- `seed.js` inserts starter demo data
- `data/daily_activity.db` is the generated database file

## Commands

```bash
npm run db:init
npm run db:seed
```
